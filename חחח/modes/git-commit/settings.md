# Git Commit — Custom Mode Settings

הגדרות מומלצות ב-UI של Cursor (Add custom mode):

| שדה | ערך |
|-----|-----|
| **Name** | `Git Commit` |
| **Icon** | 🚀 (או אייקון git שתבחר) |
| **Shortcut** | `Ctrl+Shift+G` |
| **Model** | Composer 2.5 Fast (או מהיר אחר) |

## Tools — הפעל

- Search / Codebase
- Read files
- Grep
- List directory
- Terminal (Run)

## Tools — כבה

- Edit & Reapply
- MCP (לא נדרש)
- Web search (לא נדרש)

## Automation

- **Auto-run**: ✅ ON — כדי ש-git ירוץ בלי אישור בכל פעם
- **Auto-apply edits**: ❌ OFF — אין עריכת קוד

## Advanced

**Starting prompt** — העתק מתוך `prompt.md` באותה תיקייה.

**Custom instructions** — העתק מתוך `instructions.md` באותה תיקייה.
